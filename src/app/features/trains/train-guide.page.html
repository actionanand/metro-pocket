Prepare the columns

Save as UTF-8 CSV (up to 2 MB). Quoted values, commas inside quoted station names, BOM, CRLF/LF and empty optional cells are supported.

train_number
Required on the first data row. Use 1–10 digits; leading zeroes are preserved as text. Later blank cells inherit it. A different non-empty train number is rejected.
train_name
Optional. Later blanks inherit the name. Conflicting non-empty names are rejected.
running_days
Optional. Missing, blank or whitespace on the first row means Daily. Use DAILY, Mon|Wed|Fri or Monday|Wednesday|Friday. Names are case-insensitive; later blanks inherit the definition. Unknown days and conflicting definitions are rejected.
stop_sequence
Optional. If every cell is blank, sequence follows CSV row order: 1, 2, 3… Otherwise every row needs a positive integer. Partial specification and duplicate sequences are rejected. Stops sort by sequence.
station_code
Optional station code.
station_name
Required on every row.
arrival_time / departure_time
At least one is required on every row. Use strict 24-hour HH:mm, such as 06:05 or 23:59. The origin can have only departure; the destination can have only arrival. Departure cannot precede arrival within a stop.
day_offset
Days after departure day: 0 for departure day, 1 for the next day, 2 for two days later. Either fill every row with a non-negative integer or leave every row blank. Partial offsets and backwards offsets/times are rejected.

Overnight journeys

With all day offsets blank, inference starts at day 0. If a stop's first time (arrival, otherwise departure) is earlier than the previous stop's last time (departure, otherwise arrival), advance one day.

22:40 → 23:55 → 00:25 → 02:10 becomes day 0 → 0 → 1 → 1. Use explicit offsets for whole-day gaps that cannot be inferred. A midnight dwell within one stop cannot be represented by one day offset and is rejected.

Preview and replace

Choose Import Train CSV on My Trains, review the preview, then choose Import. Nothing is saved before confirmation. If the train number already exists, Cancel keeps it; Replace Schedule atomically replaces only that train. A failed import preserves its old schedule.

CSV and backups are different

CSV creates one train on Web/PWA. A Train DB backup is the complete Train database, exported as raw SQLite .db from Settings without a password or encryption.

Restore Train Backup replaces all existing Train data after preview and confirmation. Use it to move schedules between Web/PWA and Android. Android can restore and use schedules, but cannot import CSV or open this guide.
